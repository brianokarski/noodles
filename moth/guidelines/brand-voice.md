## Defining Brand Personality

### The Five Personality Axes

Every brand exists on a spectrum across these dimensions:

```
FORMAL ←──────────────────────────────────→ PLAYFUL
   │                                           │
   Serious                                    Casual
   Corporate                                   Fun
   Traditional                               Quirky
   Authoritative                             Friendly

TRADITIONAL ←─────────────────────────────→ MODERN
   │                                           │
   Classic                                 Innovative
   Timeless                                 Cutting-edge
   Heritage                                 Progressive

SERIOUS ←─────────────────────────────────→ FRIENDLY
   │                                           │

   Distant                                   Approachable

LUXURY ←──────────────────────────────────→ ACCESSIBLE
```

## Voice Principles

### Defining How the Brand Speaks

**Vocabulary:**
- Simple and clear vs. sophisticated and technical?
- Industry jargon acceptable?
- First person (we) or third person?

**Tone:**
- Enthusiastic or understated?
- Humorous or straight?
- Empathetic or matter-of-fact?

**Rhythm:**
- Short, punchy sentences or flowing prose?
- Headlines that command or invite?
- Calls to action that push or pull?

### Example Voice Profiles

**Tech Startup (Friendly Modern):**
```
We're here to make [complex thing] simple.
No jargon. No fuss. Just results.
→ Headlines: Direct, benefit-focused
→ Body: Conversational, clear
→ CTAs: Inviting ("Get started" not "Submit")
```

**Financial Services (Trustworthy Professional):**
```
Your financial future, guided with care.
→ Headlines: Reassuring, expertise-forward
→ Body: Clear but professional
→ CTAs: Action-oriented but serious
```

**Creative Agency (Bold Playful):**
```
Let's make something unforgettable.
→ Headlines: Provocative, creative
→ Body: Confident, witty
→ CTAs: Energetic ("Let's go")
```

## Personality Keywords

Define 3-5 words that capture the brand essence:

### Primary Keywords (Must Always Apply)
```
Example: Innovative, Trustworthy, Approachable
```

### Secondary Keywords (When Appropriate)
```
Example: Bold, Playful, Sophisticated
```

### Never Keywords (Anti-patterns)
```
Example: Aggressive, Corporate, Boring
```

## Application to Design Decisions

### When the Agent Ideates

The brand personality should inform:

**Color Selection:**
```
Playful brand → Saturated, varied palette
Serious brand → Muted, limited palette
Luxury brand → Minimal, refined palette
```

**Typography Choices:**
```
Formal brand → Traditional serif, structured layouts
Modern brand → Geometric sans, asymmetric layouts
Friendly brand → Rounded fonts, open spacing
```

**Component Styling:**
```
Playful brand → Rounded corners, shadows, color fills
Minimal brand → Sharp corners, borders, monochrome
Luxury brand → Thin borders, ample whitespace, restraint
```

**Motion Behavior:**
```
Playful brand → Bouncy springs, expressive timing
Professional brand → Smooth eases, subtle transitions
Premium brand → Slow, elegant, purposeful
```

**Imagery Approach:**
```
Approachable brand → Real people, candid moments
Aspirational brand → Lifestyle imagery, perfect scenarios
Technical brand → Product-focused, abstract
```

## Voice in UI Copy

### Microcopy Guidelines

**Buttons:**
```
Formal: Submit Application
Friendly: Get Started
Playful: Let's Go!
```

**Error Messages:**
```
Formal: An error has occurred. Please try again.
Friendly: Oops! Something went wrong. Let's try that again.
Playful: Well, that didn't work. Give it another shot?
```

**Empty States:**
```
Formal: No items found.
Friendly: Nothing here yet. Let's add something!
Playful: *crickets* — Add your first item to get started.
```

**Loading States:**
```
Formal: Loading...
Friendly: Just a moment...
Playful: Fetching the good stuff...
```

**Success Messages:**
```
Formal: Action completed successfully.
Friendly: Done! Your changes have been saved.
Playful: Boom! Nailed it.
```

## Competitive Positioning

### Voice Differentiation

Map competitors on the personality axes:

```
            PLAYFUL
                ▲
                │
      Competitor A
                │      ★ OUR BRAND
    ────────────┼────────────► MODERN
                │
     Competitor B
                │
            FORMAL
```

Find whitespace in the market. If competitors are all formal and traditional, consider modern and friendly.

## Validation Questions

When reviewing design work, ask:

1. **Does this feel like our brand could have made it?**
2. **Would our customers recognize this as us?**
3. **Is it consistent with how we speak elsewhere?**
4. **Does it differentiate from competitors?**
5. **Is it appropriate for this specific context?**

## Evolution Guidelines

Brands evolve. Document:

**Current State:**
Where is the brand personality today?

**Desired State:**
Where should it move over time?

**Transition Strategy:**
How gradual? What changes first?

```
Example Evolution:
"We're shifting from Corporate → Approachable over 12 months.
Phase 1: Update tone of voice, keep visuals
Phase 2: Introduce warmer color palette
Phase 3: Refresh typography to friendlier fonts
Phase 4: Update motion to be more expressive"
```

## For the Design Agent

When the Moth agent generates designs, it should:

1. **Reference personality axes** for every decision
2. **Stay within keyword boundaries** (always/never)
3. **Adjust tone per touchpoint** (see matrix)
4. **Document rationale** connecting choices to personality
5. **Flag when a request conflicts** with brand personality

```
Example Agent Output:

"I've designed this hero section with:
- Cabinet Grotesk display type (modern, bold → matches 0.8 modern axis)
- Warm orange accent (friendly → matches 0.7 friendly axis)  
- Subtle spring animation (playful but not excessive → matches 0.6 playful)
- Clean whitespace (professional substrate for friendly overlay)

This aligns with the 'Innovative, Trustworthy, Approachable' keywords."
```
