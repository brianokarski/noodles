# Panel Lab

Randomized panel layouts for any artboard size. Set a canvas, columns and gap, then roll. Panels fill with geometric shape tiles, solid fields and type, and every layout exports as SVG.

Open `index.html`. Space to reroll.

To put a logo in the first panel, set `SHOP_LOGO = { d, vw, vh }` near the top of the script with your own SVG path data.
