# Handle Distances

A RoboFont 4 extension that displays the distance between bezier handles and their anchor points.

## What it does

When you open a glyph in the glyph editor, this extension automatically shows the distance (in units) from each anchor point to its bezier control handles. The distances appear as red text at the midpoint of each handle.

This helps you equalize handle lengths to create more symmetrical, balanced curves.

## Installation

Double-click the `HandleDistances.roboFontExt` folder to install in RoboFont 4.

## Requirements

- RoboFont 4.0 or later
