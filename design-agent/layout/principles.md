# Layout Principles

> Sources: Müller-Brockmann *Grid Systems in Graphic Design*, Swiss layout references, Emil Ruder *Typography*

---

## Core Rules

### 1. Grid is law
Every element snaps to a mathematical grid structure. Whether simple two-column or dense multi-column, the underlying structure must be present and legible.

### 2. Reduce visual elements
Fewer elements incorporated into a grid system creates compact planning, intelligibility, clarity, and orderliness. If it doesn't serve the content, remove it.

### 3. White space is active design
Negative space is treated with the same intentionality as filled space. Pages are not filled to capacity — emptiness is deployed to create emphasis, rhythm, and breathing room.

### 4. Clarity and order = credibility
Present information with clear and logical titles, subtitles, texts, illustrations and captions. Orderliness creates trust and professionalism.

### 5. Image size reflects importance
Determine the size of pictures according to their importance for the subject. Size = hierarchy.

---

## Grid Systems

- **12-column grid** as default foundation — provides maximum flexibility for 1, 2, 3, 4, 6-column arrangements
- **8-field grid** for a good balance between structure and flexibility — accommodates narrow and wide formats
- Grid is a tool, not a guarantee — a good sense of composition and rhythm is still essential
- Discipline within the grid prevents restlessness — various sizes without discipline = chaos

## Alignment

- **Flush-left alignment** dominant — ragged right, natural word spacing
- Align top and bottom edges of images with grid lines, text accordingly
- Set captions on the baseline of columns
- Page numbers positioned consistently — distance from content = column gutter width
- Bilateral symmetry across spreads creates formal, architectural order

## Spacing Scale

- Use a mathematical spacing scale (e.g., 4, 8, 16, 24, 32, 48, 64, 96, 128)
- Column gutters and element spacing should be consistent multiples
- One or more empty lines to separate hierarchical zones
- The space between elements communicates their relationship — closer = related, farther = separate

## Composition

- **Three-zone vertical structure**: header zone (oversized identifiers) → content zone → footer zone (metadata, page numbers)
- Mirror-image structures across spreads for formal order
- Systematic repetition: once a layout system is established, apply it consistently — variation comes from content, not from changing the system
- Photography as rectangular content blocks placed precisely on grid — never overlapping, rotated, or given effects

## Do's and Don'ts

**Do:**
- Establish the grid before placing any content
- Design from the double-spread / full-screen outward
- Use extreme scale contrast between zones
- Let the grid breathe — not every cell needs to be filled
- Create consistent vertical rhythm across pages

**Don't:**
- Decorate — no drop shadows, gradients, decorative borders, ornamental rules
- Break the grid without a deliberate compositional reason
- Use different spacing values arbitrarily — stay on the scale
- Overlap elements or use rotation for "dynamism" (let content and scale do the work)
- Design pages in isolation — consider the sequence
