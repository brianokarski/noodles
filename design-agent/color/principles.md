# Color Principles

> Sources: Swiss layout references, *Designing Brand Identity*, K-HOLE, cross-reference analysis

---

## Core Rules

### 1. Black and white first
Six of seven Swiss references are strictly monochrome. Start every design in black and white. If it doesn't work without color, color won't save it.

### 2. One accent color maximum
When color is used, it's a single hue deployed functionally — for section labels, key stats, CTAs, and callout blocks. Never decorative.

### 3. Accent occupies <15% of surface area
Color is scarce and therefore powerful. The less you use, the more impact each instance carries.

### 4. A limited palette signals quality
Constraint = intentionality = taste. A considered color strategy impacts recognition and creates emotional connection.

### 5. Not-quite-black, not-quite-white
Pure #000000 and #FFFFFF are harsh on screen. Use near-black (rgb 5,5,5) and off-white (rgb 247,247,242) for sophistication.

## Grey Scale for Hierarchy

| Role | Opacity/Value | Example |
|------|--------------|---------|
| Background | 2-5% white | Near-black canvas |
| Ghost elements | 8% white | Background section numbers |
| Borders/rules | 15-20% white | Divider lines, card strokes |
| Metadata/footer | 30% white | Page numbers, confidential labels |
| Secondary text | 45-50% white | Descriptions, supporting copy |
| Body text | 60% white | Paragraphs, card descriptions |
| Primary text | 95-97% white | Headlines, brand names |
| Accent | Full saturation | Section labels, stats, CTAs |

## Color Pairing Patterns

**Dark mode (primary):**
- Background: near-black
- Text: off-white hierarchy (see grey scale above)
- Accent: one saturated warm or cool hue

**Accent block reversal:**
- Accent color as fill (large card or strip)
- Near-black text on accent background
- Creates high-contrast focal point

## Do's and Don'ts

**Do:**
- Test every design in greyscale first
- Use color to signal function (this is a label, this is a stat, this is a CTA)
- Maintain consistent accent color across all slides/pages
- Use grey values to create depth without introducing new hues

**Don't:**
- Use color as decoration or to "make it pop"
- Introduce a second accent color — if you need variety, adjust value/opacity of the single accent
- Use gradients, shadows, or color effects
- Apply color to background elements — backgrounds are black or near-black
