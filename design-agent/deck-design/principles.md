# Deck Design Principles

> Synthesized from all sources — typography, layout, brand identity, and Swiss design references

---

## Core Rules

### 1. Each slide does one thing exceptionally
Fragment to focus. Don't cram multiple ideas onto one page. One headline, one message, one visual moment per slide.

### 2. Three-zone vertical structure
Every slide has: header zone (section identifiers, labels) → content zone (headline + supporting material) → footer zone (metadata, pagination, brand mark).

### 3. Pacing is narrative
The sequence of slides tells a story with progression, build-up, climax, and payoff. Vary density and white space across slides to create rhythm.

### 4. Typography carries the design
No clip art, no stock photography filler, no decorative elements. Type weight, scale, and position do all the work. Accent color is used functionally, not decoratively.

### 5. Restraint signals confidence
A limited palette, one typeface, generous white space — these limitations signal intentionality. Leave the audience wanting more, not overwhelmed.

## Slide Structure

### Standard 16:9 frame (1920 × 1080)

**Margins:** 80px left/right, 40px top, footer zone starts at y:1040

**Header zone (y: 0-120):**
- Section label: 14px, uppercase, wide tracking (8px), accent color
- Ghost section number: 200px, 8% opacity background element
- Slide metadata: 11px, grey, right-aligned

**Content zone (y: 120-1000):**
- Headline: 96-180px, Black weight, tight tracking (-3 to -6px)
- Supporting content: stat blocks, cards, body text, or empty space
- Maximum 3-4 supporting elements per slide

**Footer zone (y: 1040-1080):**
- Thin rule (1-2px, 20% grey)
- Brand name + section identifier: 11px, wide tracking, 30% grey
- Page number or CTA when appropriate

## Color Usage

- **Black background dominant** (rgb 5, 5, 5 — not pure 0,0,0)
- **Off-white text** (rgb 247, 247, 242 — not pure white)
- **One accent color only** — used for section labels, stat values, CTA strips, and key callout blocks
- **Grey scale for hierarchy**: 30% for metadata, 50% for secondary text, 60% for body
- Accent color should occupy <15% of any given slide's area

## Content Patterns

**Title slide:** Brand name at maximum scale, tagline at body scale, accent shape as visual anchor, metadata in corners

**Statement slide:** One provocative headline filling 40-60% of the slide, supporting stats or manifesto text below

**Detail slide:** Cards or blocks on a grid, each with: category label (accent) → name (white, bold) → description (grey). 2-4 items max.

**CTA slide:** Full-width accent-color strip with a single line of text. High contrast reversal (dark text on accent).

## Do's and Don'ts

**Do:**
- Use the grid consistently across all slides
- Create visual rhythm by varying slide density (dense → sparse → dense)
- Let headlines breathe — negative space above and below
- Use rules (thin lines) to separate zones, not boxes or containers
- Number sections for navigability

**Don't:**
- Center-align text (flush-left always)
- Use more than one accent color
- Add decorative elements, icons, or illustrations without purpose
- Put body-length paragraphs on slides — if it needs that many words, it's a document
- Use transitions or animation cues in the static design
